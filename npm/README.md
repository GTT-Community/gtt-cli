# gtt-cli

The GTT CLI: the operational doorway into [GTT Bootstrap](https://github.com/GTT-Community/gtt-bootstrap).

```bash
npm install -g gtt-cli
gtt version
```

This package installs the native `gtt` binary for your platform (Linux, macOS, Windows; x64, arm64) from the
matching [GitHub release](https://github.com/GTT-Community/gtt-cli/releases), verified against its SHA-256 checksum.
GTT Bootstrap also needs `git`, `bash` and `python3` (on Windows: Git for Windows and Python 3).

Documentation: https://github.com/GTT-Community/gtt-cli#readme
