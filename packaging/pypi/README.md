# gtt-cli

The GTT CLI: the operational doorway into [GTT Bootstrap](https://github.com/GTT-Community/gtt-bootstrap).

```bash
uv tool install gtt-cli     # or: uvx gtt-cli version, pipx install gtt-cli
gtt version
```

This package carries the native `gtt` binary for your platform (Linux, macOS, Windows; x86_64, arm64); no Python
code runs when you call `gtt`. GTT Bootstrap also needs `git`, `bash` and `python3` (on Windows: Git for Windows and
Python 3).

Documentation: https://github.com/GTT-Community/gtt-cli#readme
